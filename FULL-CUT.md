## DECISIONS TAKEN IN THE ASSEMBLY

- **The reshot call replaces the original.** Wardrobe now matches the run.
- **The reshot village scene replaces the original**, for the performance and the four
  clean lines — the diamond fault is the same in both, so nothing was lost by switching.
- **The boat chase sits before Totem Creek**, while all seven are alive, so it plays as a
  firefight rather than a last stand.
- **The 12-second diamond insert is NOT in this cut.** It renders as gold-veined quartz.
  Cutting it in would have made the diamond problem worse, not better.
- **The drone screen precedes the crossing**, so the audience knows what is under the
  water and the team does not.

## TIMEBASE — A TRAP WORTH RECORDING

The cold-open clip `3f1c7d96` is 2560x1440 and had to be downscaled. The first downscale
wrote `time_base 1/24000` while all 57 other clips are `1/90000`. The concat demuxer
adopts the FIRST file's timebase, so the finished film reported **93 minutes** instead of
24:47 — every duration inflated by exactly 90000/24000 = 3.75x.

**Always pass `-video_track_timescale 90000` when re-encoding a clip for this film.**
