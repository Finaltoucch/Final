# Final Touch (@finaltoucch): brand rules (owner-approved)

## Fonts
- **Thumbnails / Reel covers: Anton only** (`brand/fonts/Anton-Regular.ttf`, Higgsfield font-reference media `21efca1d-695a-4695-856c-48d5c4e24990`). Pass it as an image reference on every thumbnail.
- **Carousel inner slides: keep the existing slide font** (the heavy rounded sans used on the Faceless Stories / Upwork vs Contra slides). Do NOT convert slides to Anton.
- Text colour: **black #0A0A0A on light/white backgrounds**, **lime #C6FF00 (soft glow) on dark backgrounds**.
- Title = big word + feature word as an echo stack ×3 (100 / 60 / 25% opacity).

## Thumbnails
- Full, uncropped photo. Never add bands, bars, boxes or panels, and never cut off heads, faces or hands.
- Text never covers a face.

## Face, wardrobe, voice
- Always pass the owner's real reference photos so the face matches him. Black thick-frame glasses in every shot; a different nice outfit per scene.
- Voice: Higgsfield element "Finaltouch-" `f20af7a3-2416-4cb8-b394-688e71bcc43d`, speech_rate +30, loudness +10, with a music bed and sound effects.
- Never name a city; say "right here from my home".
